## 📝 PASSO A PASSO RÁPIDO

### Passo 1️⃣
```
Abra GitHub Desktop
Clique em: File → New Repository
```

### Passo 2️⃣
```
Preencha:
• Name: powerpoint-app-pro
• Local Path: sua pasta do projeto
```

### Passo 3️⃣
```
Clique: Create Repository
```

### Passo 4️⃣
```
Clique: Publish repository (azul)
Escolha: Public
```

### Passo 5️⃣
```
Clique: Publish Repository
```

### Pronto! ✅
```
Seu código está no GitHub!
Compartilhe o link com quem quiser!
```
