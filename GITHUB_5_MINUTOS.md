# 🎯 INÍCIO RÁPIDO - GITHUB EM 5 MINUTOS

## ⚡ TL;DR (Versão Ultra-Curta)

```
1. Abra GitHub Desktop
2. File → New Repository
3. Nome: powerpoint-app-pro
4. Local Path: Sua pasta do projeto
5. Create Repository
6. Publish repository (botão azul)
7. Escolha Public
8. PRONTO! 🎉
```

Seu repositório estará em:
```
https://github.com/seu-usuario/powerpoint-app-pro
```

## 🎯 EXATAMENTE O QUE FAZER

### Clique 1: Abra GitHub Desktop

```
Windows:
  Pesquise "GitHub Desktop"
  Clique no ícone
  Espere abrir
```

### Clique 2: Ir para File

```
No menu superior:
  File ← Clique aqui
  ↓
  New Repository ← Clique aqui
```

### Clique 3: Preencher Formulário

```
Tela que vai aparecer:
┌─────────────────────────────────┐
│ Name:                           │
│ [powerpoint-app-pro]            │
│                                 │
│ Description:                    │
│ [PowerPoint App Pro]            │
│                                 │
│ Local Path:                     │
│ [C:\Users\ide_c\OneDrive\...]   │
│                                 │
│ ☑ Initialize with README        │
└─────────────────────────────────┘

Copie e Cole:
Nome: powerpoint-app-pro
Description: PowerPoint App Pro - App de apresentações moderno
Local Path: C:\Users\ide_c\OneDrive\Área de Trabalho\Nova pasta
```

### Clique 4: Create Repository

```
Botão grande azul embaixo:
[Create Repository] ← Clique aqui
```

### Clique 5: Publish Repository

```
Depois de criar, vai aparecer:
[Publish repository] ← Clique aqui (botão azul no topo)
```

### Clique 6: Confirmar Public

```
Nova tela:
┌─────────────────────────────┐
│ Publish Repository          │
│                             │
│ Keep this code private      │
│ ☐ Private                   │
│ ☑ Public ← DEIXE MARCADO   │
│                             │
│ [Publish Repository]        │
└─────────────────────────────┘
```

### Pronto! ✅

```
Seu código está no GitHub!
Abra o navegador e acesse:

https://github.com/seu-usuario/powerpoint-app-pro
```
