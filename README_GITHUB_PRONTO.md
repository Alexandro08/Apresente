## 🚀 Como Proceder AGORA

### **OPÇÃO A: Se tem GitHub Desktop** (Mais Fácil!)

```
1. Abra GitHub Desktop
2. File → New Repository
3. Nome: powerpoint-app-pro
4. Local Path: Sua pasta do projeto
5. Create Repository
6. Clique em "Publish repository" (botão azul)
7. Escolha Public
8. Pronto! 🎉
```

Seu repositório estará em:
```
https://github.com/seu-usuario/powerpoint-app-pro
```

---

### **OPÇÃO B: Se quer usar Terminal**

1. Instale Git: https://git-scm.com/download/win
2. Reinicie o terminal
3. Execute no PowerShell:

```powershell
cd "c:\Users\ide_c\OneDrive\Área de Trabalho\Nova pasta"

# Configure Git (primeira vez)
git config --global user.name "Seu Nome"
git config --global user.email "seu.email@github.com"

# Inicialize
git init
git add .
git commit -m "Initial commit: PowerPoint App Pro"

# Crie repositório em https://github.com/new
# Depois execute (substitua seu-usuario):
git remote add origin https://github.com/seu-usuario/powerpoint-app-pro.git
git branch -M main
git push -u origin main
```
