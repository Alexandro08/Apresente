# ⌨️ Cheat Sheet - PowerPoint App Pro

## 🎬 Modo Apresentação

| Atalho | Ação |
|--------|------|
| `→` | Próximo slide |
| `←` | Slide anterior |
| `Espaço` | Próximo slide |
| `F` | Mostrar/Ocultar painel de slides |
| `Esc` | Sair da apresentação |
| **Clique em slide no painel** | **Mudar slide sem sair** ⭐ |

## 🖊️ Modo Edição

| Atalho | Ação |
|--------|------|
| `Ctrl+Z` | Desfazer |
| `Ctrl+Y` | Refazer |
| **Click em Novo Slide** | Adicionar slide |
| **Hover + 📋** | Duplicar slide |
| **Hover + ✕** | Deletar slide |
| **Arrastar slide** | Reordenar |

## 🎨 Formatação de Texto

Ao clicar em título/conteúdo, você tem acesso a:

| Opção | Valores |
|-------|---------|
| **Fonte** | Arial, Verdana, Georgia, Times New Roman, Courier New, Trebuchet MS |
| **Tamanho** | 8-120px (presets: 16, 24, 32, 48) |
| **Bold** | ✓ Ativado/Desativado |
| **Italic** | ✓ Ativado/Desativado |
| **Underline** | ✓ Ativado/Desativado |
| **Cor** | Paleta pré-definida + seletor customizado |

## 🎯 Fluxo Básico

### 1️⃣ Criar Apresentação
```
1. Clique em ➕ Novo Slide
2. Digite título
3. Digite conteúdo
4. Pronto! ✅
```

### 2️⃣ Formatar
```
1. Clique no texto
2. Escolha fonte, tamanho, cor
3. Mudanças em tempo real
```

### 3️⃣ Apresentar
```
1. Clique em ▶️ Apresentar
2. Use setas ou espaço
3. Clique em slides no painel
4. Pressione Esc para sair
```

## 🖱️ Interações do Mouse

```
Normal          → Clique: Seleciona slide
Hover           → Mostram botões 📋 e ✕

```

### Na Edição
```
Clique          → Seleciona elemento
Triplo clique   → Seleciona tudo
Drag texto      → Copia/move
Scroll          → Navega na lista
```

### Na Apresentação
```
Clique slide    → Muda slide (painel)
Clique botão    → Navega ou sai
Tecla           → Atalho de ação
```

## 🎯 Combinações Comuns

### Workflow Rápido
```
1. ➕ Novo Slide
2. Digite conteúdo
3. Ctrl+Z para desfazer (se errou)
4. ▶️ Apresentar
5. Espaço para navegar
6. Esc para sair
```

### Editar e Formatar
```
1. Clique no título
2. Selecione cor + tamanho
3. Clique no conteúdo
4. Ajuste formatação
5. Ctrl+Z se não gostar
```

### Reordenar Slides
```
1. Arraste slide 1 para posição
2. Arraste slide 2 para posição
3. Continue...
4. Ctrl+Z desfaz tudo se errou
```

## 🆘 Problemas Comuns

| Problema | Solução |
|----------|---------|
| App não carrega | Recarregue página (F5) |
| Slides não salvam | Verificar localStorage |
| Formatação desaparece | Desfaça (Ctrl+Z) e refaça |
| Painel não aparece | Clique F ou 👁️ na apresentação |
| Não consegue sair | Pressione Esc |

## 🎊 Dicas de Mestre

1. **Use Ctrl+Z frequentemente** - Você pode desfazer tudo
2. **Memorize atalhos** - Velocidade aumenta muito
3. **Organize slides com drag-drop** - Mais rápido que deletar/criar
4. **Exporte regularmente** - Proteja seu trabalho
5. **Use cores com sabedoria** - Legibilidade é importante
